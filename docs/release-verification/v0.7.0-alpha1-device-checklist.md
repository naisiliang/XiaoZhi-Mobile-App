## Required real-device acceptance (P0)

Install the APK produced by the GitHub run for the recorded reviewed ref on a physical arm64 Android device. Record device model, Android version, run URL, APK SHA-256, and tester/date.

- [ ] First launch and permissions complete without exposing secrets or raw sensitive captures.
- [ ] Custom `小白小白` wake is accepted and starts exactly one new conversation session.
- [ ] A continuous voice turn appends to the current session; a second wake after exit starts a new session.
- [ ] Voice exit ends the session, returns to offline wake standby, and does not force-stop the app.
- [ ] Overlay appears for an active session and hides after exit.
- [ ] `正在听你说` appears only during real AudioRecord capture; TTS and ASR do not overlap.
- [ ] Original local controls (including app launch, map/navigation, media, flashlight, and media volume) retain their established behavior and truthful result feedback.
- [ ] Settings changes persist after leaving and reopening Settings.

Do not mark this section complete from source tests, a successful API response, or a workflow result alone.
