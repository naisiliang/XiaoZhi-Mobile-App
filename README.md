# XiaoZhi Mobile App v0.6.4

Android 本地语音助手：离线唤醒、离线 Paraformer ASR、连续会话、任意已安装 App 控制、地图导航、AI 安全工具调用。

## v0.6.4 重点

- **冻结并保留 v0.6.3 自定义唤醒**：`小白小白` 等动态唤醒词编译/KWS 模型/阈值/stream 应用逻辑不修改，并有独立回归保护。
- 连续会话改为明确状态：等待唤醒、监听、识别、执行、播报、准备继续监听、退出；悬浮层只在真实开麦后显示“正在听你说…”。
- 成功手机操作会播报结果；本次会话第一条成功操作使用“<结果>，你有什么需求请说？”，后续使用“<结果>，请继续说。”；TTS 完成后约 120–180ms 才重新开麦。
- 透明悬浮层改成**面板大小可触摸窗口**：右上角 `×` 可退出，双击面板也可退出；面板以外保持触摸穿透，不挡微信/高德/桌面操作。
- 智能退出支持 `退出 / 退下 / 没什么事了 / 先这样吧 / 再见` 等，并防止把 `退出微信 / 退出登录 / 怎么退出这个页面` 错判成退出助手；模糊表达可用 AI 做无工具二分类兜底。
- 新增自然语言媒体音量：`最大/最高/开满`、`百分之七十`、`70%`、`一半`、`静音`、`大一点/小一点`。只控制 `STREAM_MUSIC`，执行后重新读取 Android 实际媒体音量再播报，并显示系统音量条。
- 增加约 1.5 秒重复设备指令抑制，减少 ASR 重复识别导致的重复打开 App/重复执行。
